ProSvet — учебный курс

Как открыть сайт:
1. Распакуйте архив в удобную папку.
2. Откройте файл index.html двойным щелчком мыши.
3. Для перехода между разделами используйте меню сайта.

Интерактивные возможности:
- Переключатель светлой и тёмной темы находится в верхней части сайта. Выбранная тема запоминается в этом браузере.
- На страницах лекций отображается полоса прогресса чтения.
- После изучения лекции нажмите «Отметить лекцию как изученную». Отметки и общий прогресс курса сохраняются в локальном хранилище браузера.
- На странице программы и главной странице отображается общий прогресс из 16 лекций.
- Кнопка со стрелкой внизу справа возвращает к началу страницы после прокрутки.
- Некоторые дополнительные пояснения можно раскрыть нажатием на заголовок блока.

Сайт работает локально, без сервера и установки дополнительных программ. Для сохранения темы и прогресса не очищайте данные сайта в браузере. При открытии в другом браузере или на другом устройстве отметки будут отдельными.
