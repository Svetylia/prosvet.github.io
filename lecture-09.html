9.1. Понятие HTML и его роль в разработке сайтов

HTML (HyperText Markup Language) — язык гипертекстовой разметки, который используется для создания структуры веб-страниц. Он определяет, какие элементы присутствуют на странице: заголовки, абзацы, изображения, ссылки, списки, таблицы, формы и другие объекты.

HTML не является языком программирования в классическом понимании. Он не предназначен для выполнения сложных вычислений или реализации алгоритмов. Его основная задача — описывать структуру и смысловое содержание документа.

При разработке сайта HTML взаимодействует с другими технологиями:

  • HTML отвечает за структуру и содержание страницы;
  • CSS определяет внешний вид и расположение элементов;
  • JavaScript обеспечивает интерактивность и динамическое поведение.

Например, при создании карточки образовательного курса HTML определяет наличие заголовка, описания, изображения и кнопки. CSS задаёт цвет фона, размеры, отступы и расположение этих элементов. JavaScript может отвечать за открытие подробной информации после нажатия на кнопку.

Таким образом, дизайнеру важно понимать возможности HTML, поскольку структура документа напрямую влияет на реализацию визуального макета.

9.2. Структура HTML-документа

Любая стандартная HTML-страница имеет базовую структуру, которая сообщает браузеру, что документ написан на HTML5, и определяет его основные области.

Пример:

HTML · базовая структура документа
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Образовательный проект</title>
</head>
<body>
  <header>
    <h1>Добро пожаловать на курс</h1>
  </header>
  <main>
    <p>Здесь размещается основное содержание страницы.</p>
  </main>
  <footer>
    <p>© 2026 ProSvet</p>
  </footer>
</body>
</html>

Рассмотрим основные элементы.

<!DOCTYPE html> сообщает браузеру, что документ использует современный стандарт HTML5.

Элемент <html> является корневым элементом страницы. Атрибут lang="ru" указывает язык содержимого, что полезно для браузеров и вспомогательных технологий.

Раздел <head> содержит служебную информацию: название страницы, кодировку, настройки отображения, подключение таблиц стилей и другие метаданные. Большая часть содержимого этого раздела непосредственно не отображается на странице.

Раздел <body> включает элементы, которые пользователь видит и с которыми взаимодействует.

Атрибут viewport особенно важен для адаптивной вёрстки. Он позволяет браузеру корректно учитывать ширину устройства при отображении страницы.

9.3. Основные HTML-элементы

HTML содержит большое количество элементов, каждый из которых предназначен для определённого типа содержимого.

Заголовки. Элементы <h1>–<h6> используются для создания заголовков разных уровней. Они формируют иерархию содержания документа.

Абзацы. Элемент <p> предназначен для оформления текстовых абзацев.

Ссылки. Элемент <a> создаёт гиперссылки, позволяющие переходить на другие страницы или внешние ресурсы.

Изображения. Элемент <img> используется для добавления графических материалов. Атрибут src указывает путь к изображению, а alt содержит его текстовое описание.

Списки. Упорядоченные списки создаются с помощью <ol>, неупорядоченные — с помощью <ul>. Каждый пункт списка оформляется элементом <li>.

Контейнеры. Элементы <div> и <span> используются для группировки содержимого и последующего оформления с помощью CSS. <div> обычно применяется для блочных групп, а <span> — для отдельных фрагментов текста.

Например, список тем образовательного курса можно оформить следующим образом:

HTML
<h2>Программа обучения</h2>
<ul>
<li>Основы веб-дизайна</li>
<li>UX-исследования</li>
<li>Прототипирование</li>
<li>Основы HTML и CSS</li>
</ul>

Важно использовать элементы по назначению. Например, не следует создавать заголовок исключительно ради крупного шрифта, если по смыслу он является обычным абзацем. Внешний вид текста лучше настраивать через CSS.

9.4. Семантическая разметка HTML5

Одним из важных принципов современной веб-разработки является семантическая разметка. Она предполагает использование элементов, которые не просто группируют содержимое, а обозначают его смысл и назначение.

К основным семантическим элементам относятся:

  • <header> — верхняя часть страницы или отдельного раздела;
  • <nav> — блок навигации;
  • <main> — основное содержание документа;
  • <section> — тематический раздел;
  • <article> — самостоятельный материал;
  • <aside> — дополнительное или сопутствующее содержимое;
  • <footer> — нижняя часть страницы или раздела.

Например, страница отдельной лекции может иметь следующую структуру:

HTML
<header>
<h1>Основы HTML5</h1>
</header>
<nav>
<a href="index.html">Главная</a>
<a href="lectures.html">Лекции</a>
</nav>
<main>
<article>
<h2>Структура веб-страницы</h2>
<p>HTML определяет структуру документа...</p>
</article>
<aside>
<h2>Дополнительные материалы</h2>
<p>Полезные источники по теме.</p>
</aside>
</main>
<footer>
<p>Образовательный проект ProSvet</p>
</footer>

Семантическая разметка полезна не только разработчикам. Она улучшает доступность сайта, облегчает понимание структуры документа поисковыми системами и делает код более понятным для последующего сопровождения.

9.5. HTML-формы и сбор пользовательских данных

Формы позволяют пользователям вводить и отправлять информацию. Они широко применяются при регистрации, оформлении заказов, подписке на рассылки, заполнении заявок и обратной связи.

Основными элементами форм являются:

  • <form> — контейнер формы;
  • <label> — подпись поля;
  • <input> — поле ввода;
  • <textarea> — многострочное поле;
  • <select> — список выбора;
  • <button> — кнопка.

Пример формы обратной связи:

HTML · форма обратной связи
<form action="/feedback" method="post">
  <label for="name">Ваше имя</label>
  <input type="text" id="name" name="name" required>

  <label for="email">Электронная почта</label>
  <input type="email" id="email" name="email" required>

  <button type="submit">Отправить</button>
</form>

Атрибут required указывает, что поле обязательно для заполнения. Тип email позволяет браузеру выполнять базовую проверку формата электронной почты.

При проектировании форм дизайнер должен учитывать понятность подписей, размеры полей, порядок заполнения, сообщения об ошибках и состояние успешной отправки.

Выводы по лекции

HTML5 является основой структуры веб-страницы. Он определяет содержание, взаимосвязь элементов и семантику документа. Понимание HTML позволяет дизайнеру создавать макеты, которые соответствуют возможностям веб-технологий, учитывают доступность и могут быть корректно реализованы разработчиком.
