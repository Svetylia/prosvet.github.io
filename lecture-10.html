10.1. Понятие CSS и его назначение

CSS (Cascading Style Sheets) — каскадные таблицы стилей, предназначенные для управления внешним видом HTML-документов.

Если HTML отвечает за структуру страницы, то CSS определяет её визуальное представление. С помощью CSS можно изменять цвет текста и фона, задавать размеры элементов, настраивать отступы, выравнивание, границы, тени, анимации и адаптивное поведение.

Например, HTML может содержать заголовок:

HTML 
<h1>Добро пожаловать на ProSvet</h1>

А CSS определяет его оформление:

CSS 
h1 {
color: #596B4D;
font-size: 40px;
text-align: center;
}

Такой подход позволяет разделить содержание и оформление. Это особенно важно для крупных сайтов, где один набор стилей может применяться сразу к нескольким страницам.

10.2. Способы подключения CSS

Существует три основных способа добавления стилей.

Встроенные стили задаются непосредственно внутри HTML-элемента с помощью атрибута style.

HTML 
<p style="color: green;">Текст страницы</p>

Этот способ подходит для отдельных случаев, но не рекомендуется для оформления больших проектов, поскольку усложняет поддержку кода.

Внутренние стили размещаются внутри элемента <style> в разделе <head>.

HTML 
<head>
<style>
p {
color: green;
}
</style>
</head>

Внешняя таблица стилей представляет собой отдельный файл с расширением .css, который подключается через элемент <link>.

HTML · подключение внешней таблицы стилей 
<head>
  <link rel="stylesheet" href="style.css">
</head>

Внешний файл является наиболее удобным вариантом для многостраничного сайта. Например, если проект включает главную страницу, каталог и страницу отдельной лекции, все они могут использовать один общий CSS-файл.

Это обеспечивает единый стиль и позволяет изменять оформление всего проекта централизованно.

10.3. Селекторы и каскадность

Селектор определяет, к каким HTML-элементам будут применяться CSS-правила.

Наиболее распространены следующие виды селекторов.

Селектор элемента выбирает все элементы определённого типа:

CSS 
h1 {
color: #596B4D;
}

Селектор класса применяется к элементам с указанным значением атрибута class:

CSS · селектор класса 
.card {
  background-color: #F5F1E8;
}

В HTML его можно использовать следующим образом:

HTML 
<div class="card">
<h2>Лекция 1</h2>
</div>

Селектор идентификатора выбирает элемент с конкретным значением id:

CSS · селектор идентификатора 
#main-title {
  font-size: 36px;
}

Важной особенностью CSS является каскадность. Если к одному элементу применяются несколько правил, браузер определяет итоговый стиль с учётом происхождения правил, специфичности селекторов и порядка их расположения.

Например:

CSS 
p {
color: black;
}
.description {
color: green;
}

Если абзацу присвоен класс description, его текст будет зелёным, поскольку селектор класса обладает большей специфичностью, чем селектор элемента.

Для дизайнера понимание каскадности особенно важно при работе с готовыми шаблонами и большими таблицами стилей: оно помогает находить причины конфликтов оформления.

10.4. Блочная модель CSS

Одним из фундаментальных понятий CSS является блочная модель (Box Model). Она описывает, из каких частей состоит прямоугольная область HTML-элемента.

В блочную модель входят четыре основные составляющие:

  1. Content — содержимое элемента.
  2. Padding — внутренние отступы между содержимым и границей.
  3. Border — граница элемента.
  4. Margin — внешние отступы между элементами.

Например, карточка образовательного курса может иметь текстовое содержимое, внутренние отступы, рамку и внешний отступ относительно соседних карточек.

Пример:

CSS 
.card {
width: 300px;
padding: 20px;
border: 1px solid #D8D0C2;
margin: 15px;
}

При стандартном значении box-sizing: content-box указанная ширина относится только к содержимому. Внутренние отступы и границы увеличивают итоговый размер элемента.

Поэтому в современных проектах часто используют:

CSS · универсальное правило блочной модели 
* {
  box-sizing: border-box;
}

В этом случае заданная ширина уже включает содержимое, внутренние отступы и границы. Это упрощает расчёт размеров и построение макетов.

10.5. Основные свойства CSS

CSS-свойство Назначение
color Цвет текста
background-color Цвет фона
font-family Гарнитура шрифта
font-size Размер текста
font-weight Насыщенность шрифта
width Ширина элемента
height Высота элемента
padding Внутренние отступы
margin Внешние отступы
border Граница
border-radius Скругление углов
box-shadow Тень
opacity Прозрачность

Для стилизации веб-интерфейсов применяется большое количество CSS-свойств.

Для дизайнеров особенно важно понимание единиц измерения.

px — пиксели, часто применяемые для точной настройки границ и отдельных размеров.

% — относительная величина, рассчитываемая относительно другого размера, обычно родительского элемента.

rem — единица измерения, связанная с размером шрифта корневого элемента документа.

vw и vh — единицы, зависящие от ширины и высоты области просмотра браузера.

Использование относительных единиц помогает создавать более гибкие интерфейсы.

10.6. CSS-переменные и единый визуальный стиль

В CSS можно создавать собственные переменные, которые позволяют централизованно управлять значениями цветов, размеров и других параметров.

Например:

CSS 
:root {
--main-color: #596B4D;
--background-color: #F5F1E8;
--text-color: #332F28;
--accent-color: #C58B57;
}
body {
background-color: var(--background-color);
color: var(--text-color);
}
button {
background-color: var(--main-color);
}

Если в дальнейшем потребуется изменить основной зелёный цвет проекта, достаточно поменять одно значение в переменной. Все элементы, использующие эту переменную, автоматически получат новый оттенок.

CSS-переменные особенно полезны при создании дизайн-систем и поддержании единого оформления многостраничных проектов.

Выводы по лекции

CSS отвечает за визуальное оформление веб-страниц и позволяет реализовывать дизайнерские решения средствами браузера. Понимание селекторов, каскадности, блочной модели, единиц измерения и переменных необходимо для грамотного проектирования интерфейсов и взаимодействия с frontend-разработчиками.
