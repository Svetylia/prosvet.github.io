Современная вёрстка: Flexbox и CSS Grid

Учебный материал · упражнение по желанию · вопросы для самопроверки

Цель лекции

изучить современные инструменты построения веб-макетов, разобраться в Flexbox и CSS Grid и научиться выбирать подходящий способ компоновки.

11.1. Понятие современной вёрстки

Вёрстка — процесс преобразования дизайн-макета в HTML-структуру и CSS-стили, которые браузер использует для отображения веб-страницы.

Ранее для построения сложных макетов часто применялись таблицы, плавающие элементы и позиционирование. Однако современные CSS-технологии предоставляют более гибкие инструменты, позволяющие создавать адаптивные интерфейсы с меньшим количеством кода.

К наиболее важным технологиям относятся Flexbox и CSS Grid.

Flexbox предназначен преимущественно для организации элементов вдоль одной оси — горизонтальной или вертикальной.

CSS Grid позволяет создавать двумерные сетки, одновременно управляя строками и колонками.

Обе технологии широко используются в современной веб-разработке и могут применяться совместно.

11.2. Flexbox: организация элементов в одном направлении

Flexbox — модель компоновки CSS, предназначенная для гибкого размещения элементов внутри контейнера.

Для активации Flexbox родительскому элементу задаётся свойство:

CSS 
.container {
display: flex;
}

После этого непосредственные дочерние элементы становятся flex-элементами.

Одним из главных параметров является flex-direction, определяющий направление расположения элементов.

CSS 
.container {
display: flex;
flex-direction: row;
}

Значение row располагает элементы в строку, а column — в колонку.

Для управления распределением пространства применяется justify-content.

Например:

CSS 
.container {
display: flex;
justify-content: space-between;
}

Это распределяет свободное пространство между элементами.

Свойство align-items управляет выравниванием элементов по поперечной оси.

CSS · выравнивание элементов Flexbox 
.container {
  display: flex;
  align-items: center;
}

Такой подход часто применяется при создании шапки сайта, где логотип и навигация должны располагаться на одной линии.

Другие полезные свойства:

  • gap — расстояние между элементами;
  • flex-wrap — возможность переноса элементов на новую строку;
  • flex-grow — способность элемента увеличиваться;
  • flex-shrink — способность элемента уменьшаться;
  • flex-basis — исходный размер элемента по главной оси.

11.3. Пример использования Flexbox

Предположим, необходимо создать навигационную панель образовательного сайта. Она должна включать логотип, ссылки на разделы и кнопку входа.

HTML:

HTML 
<header class="header">
<div class="logo">ProSvet</div>
<nav class="navigation">
<a href="#">Главная</a>
<a href="#">Лекции</a>
<a href="#">О курсе</a>
</nav>
<button>Войти</button>
</header>

CSS:

CSS · оформление навигационной панели 
.header {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 24px;
  padding: 20px;
}
CSS 
.navigation {
display: flex;
gap: 20px;
}

Flexbox позволяет расположить все элементы горизонтально и выровнять их по вертикали без необходимости вручную рассчитывать координаты каждого объекта.

11.4. CSS Grid: построение двумерных сеток

CSS Grid — технология компоновки, предназначенная для построения сложных сеточных макетов.

В отличие от Flexbox, который ориентирован на одну ось, Grid позволяет одновременно управлять колонками и строками.

Для создания сетки используется:

CSS 
.grid-container {
display: grid;
grid-template-columns: 1fr 1fr 1fr;
gap: 20px;
}

В данном примере создаются три колонки одинаковой ширины.

Единица fr обозначает долю доступного пространства. Например:

CSS · пропорции колонок Grid 
.grid-container {
  display: grid;
  grid-template-columns: 2fr 1fr;
}

означает, что первая колонка получит в два раза больше свободного пространства, чем вторая.

Для задания количества строк применяется grid-template-rows.

CSS 
.grid-container {
display: grid;
grid-template-columns: 1fr 1fr;
grid-template-rows: auto auto;
}

С помощью Grid можно создавать карточные каталоги, галереи, журнальные макеты, сложные информационные страницы и другие структуры.

11.5. Пример создания сетки карточек

Рассмотрим каталог лекций, состоящий из нескольких карточек.

HTML:

HTML 
<div class="lecture-grid">
<article class="lecture-card">
<h3>Лекция 1</h3>
<p>Введение в веб-дизайн</p>
</article>
<article class="lecture-card">
<h3>Лекция 2</h3>
<p>UX-исследования</p>
</article>
<article class="lecture-card">
<h3>Лекция 3</h3>
<p>Прототипирование</p>
</article>
</div>

CSS:

CSS · сетка карточек лекций 
.lecture-grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 24px;
}

.lecture-card {
  padding: 24px;
}

Запись repeat(3, 1fr) означает, что браузер создаст три одинаковые колонки.

Для более гибкой сетки можно использовать:

CSS · адаптивная сетка карточек 
.lecture-grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(240px, 1fr));
  gap: 24px;
}

Здесь браузер автоматически определяет, сколько карточек помещается в строке, учитывая минимальную ширину 240 пикселей.

11.6. Flexbox и Grid: когда что использовать

Критерий Flexbox CSS Grid
Основное назначение Одномерная компоновка Двумерная компоновка
Основная ось Одна Две
Типичные задачи Навигация, кнопки, строки Сетки карточек, макеты страниц
Управление строками и колонками Ограниченное Полноценное
Совместное применение Да Да

Важно понимать, что Flexbox и Grid не конкурируют друг с другом. Они решают разные задачи и часто используются вместе.

Например, общую структуру страницы можно построить с помощью Grid, а элементы навигации внутри шапки — с помощью Flexbox.

Выводы по лекции

Flexbox и CSS Grid являются основными инструментами современной CSS-вёрстки. Flexbox удобен для размещения элементов вдоль одной оси, а Grid позволяет создавать сложные двумерные сетки. Правильный выбор технологии помогает реализовывать макеты более гибко, сокращает количество вспомогательного кода и облегчает адаптацию интерфейсов.
