13.1. Роль JavaScript в веб-разработке

JavaScript — язык программирования, который используется для реализации интерактивного и динамического поведения веб-страниц.

Если HTML задаёт структуру, а CSS отвечает за оформление, JavaScript позволяет реагировать на действия пользователя, изменять содержимое страницы и выполнять определённые операции.

С его помощью реализуются:

  • раскрывающиеся меню;
  • модальные окна;
  • переключение вкладок;
  • слайдеры;
  • фильтрация и поиск;
  • интерактивные тесты;
  • проверка форм;
  • динамическое обновление данных.

Например, образовательная платформа может использовать JavaScript для отображения результата тестирования без перезагрузки страницы. Пользователь отвечает на вопросы, нажимает кнопку проверки и сразу видит количество правильных ответов.

Таким образом, JavaScript позволяет превратить статичную страницу в интерактивную систему.

13.2. Основы JavaScript: переменные, типы данных и условия

Для работы с JavaScript используются переменные, которые позволяют хранить значения и обращаться к ним в процессе выполнения программы.

Современный JavaScript чаще всего использует два способа объявления переменных:

JAVASCRIPT
let studentName = "Светлана";
const courseName = "ProSvet";

const используется для переменных, которым не планируется присваивать новое значение.

let используется для переменных, значение которых может изменяться.

JavaScript поддерживает несколько основных типов данных:

  • строки;
  • числа;
  • логические значения;
  • объекты;
  • массивы;
  • специальные значения null и undefined.

Пример простого условия:

JavaScript · условие проверки результата
let score = 8;

if (score >= 7) {
  console.log("Тест пройден");
} else {
  console.log("Попробуйте ещё раз");
}

Условия позволяют программе выбирать дальнейшее действие в зависимости от полученных данных.

Например, при прохождении учебного теста система может определять, достиг ли студент минимального проходного балла.

13.3. Функции и обработка событий

Функция — блок кода, предназначенный для выполнения определённой задачи. Она позволяет объединять повторяющиеся действия и использовать их в разных частях программы.

Пример:

JAVASCRIPT
function showMessage() {
alert("Добро пожаловать на ProSvet!");
}

Функцию можно вызвать в нужный момент.

Важнейшим механизмом интерактивности являются события. Событие — действие или изменение состояния, которое браузер может обнаружить и на которое программа может отреагировать.

К основным событиям относятся:

  • click — нажатие мышью или активация элемента;
  • input — изменение значения поля ввода;
  • submit — отправка формы;
  • change — изменение значения элемента;
  • keydown — нажатие клавиши;
  • mouseover — наведение указателя.

Например:

HTML
<button id="myButton">Нажми меня</button>
<script>
const button = document.getElementById("myButton");
button.addEventListener("click", function() {
alert("Кнопка работает!");
});
</script>

Здесь JavaScript находит кнопку по идентификатору и назначает обработчик события click. При нажатии появляется сообщение.

13.4. DOM и динамическое изменение страницы

DOM (Document Object Model) — объектная модель документа, которая представляет HTML-страницу в виде структуры объектов.

Браузер создаёт DOM на основе HTML-разметки. JavaScript может обращаться к этим объектам, изменять их содержимое, атрибу

ты, классы и структуру.

Например, можно изменить текст заголовка:

HTML
<h1 id="title">Добро пожаловать!</h1>
<script>
const heading = document.getElementById("title");
heading.textContent = "Начните обучение на ProSvet";
</script>

Также можно добавлять или удалять CSS-классы:

JavaScript · изменение класса элемента DOM
const card = document.querySelector(".lecture-card");
card.classList.add("active");

Это позволяет менять внешний вид элементов в ответ на действия пользователя.

Например, при нажатии на карточку лекции можно добавить класс, который выделит её рамкой или изменит цвет фона.

13.5. CSS-анимация: переходы и ключевые кадры

Не все анимации требуют JavaScript. Многие визуальные эффекты удобнее реализовывать средствами CSS.

Для плавного изменения свойств используется transition.

CSS
.button {
background-color: #596B4D;
transition: background-color 0.3s ease;
}
.button:hover {
background-color: #3F5037;
}

В данном случае цвет кнопки плавно меняется при наведении.

Для создания более сложной последовательности движения применяется @keyframes.

CSS · анимация появления карточки
@keyframes appear {
  from {
    opacity: 0;
    transform: translateY(20px);
  }

  to {
    opacity: 1;
    transform: translateY(0);
  }
}

.card {
  animation: appear 0.6s ease;
}

Здесь карточка появляется постепенно, одновременно перемещаясь снизу вверх.

CSS-анимации особенно полезны для декоративных эффектов, появления блоков, состояний кнопок и небольших переходов.

13.6. Когда необходим JavaScript, а когда достаточно CSS

CSS и JavaScript могут использоваться для создания анимации, но их назначение различается.

CSS подходит для простых визуальных переходов, изменения состояния при наведении, появления элементов и декоративных эффектов.

JavaScript необходим, когда анимация зависит от логики приложения, данных пользователя или сложной последовательности действий.

Например, плавное изменение цвета кнопки можно реализовать через CSS. А вот анимация заполнения шкалы прогресса в зависимости от количества пройденных лекций может потребовать JavaScript, поскольку её значение определяется реальными данными.

При выборе технологии важно учитывать сложность задачи, производительность и доступность.

13.7. Интерактивность и доступность

При разработке интерактивных элементов необходимо учитывать пользователей, которые управляют сайтом не только мышью, но и клавиатурой или вспомогательными технологиями.

Кнопки должны быть доступны для активации с клавиатуры. Поля форм должны иметь понятные подписи. Модальные окна должны обеспечивать корректное перемещение фокуса и возможность закрытия.

Также следует учитывать предпочтения пользователей, которые испытывают дискомфорт от интенсивной анимации. Для этого применяется системная настройка prefers-reduced-motion.

Пример:

CSS · учёт предпочтения уменьшенного движения
@media (prefers-reduced-motion: reduce) {
  * {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}

Этот пример демонстрирует один из способов сокращения анимации. В реальных проектах лучше отдельно определять, какие эффекты можно отключить или заменить упрощёнными переходами.

Главный принцип заключается в том, что интерактивность должна помогать пользователю, а не создавать дополнительные препятствия.

Выводы по лекции

JavaScript обеспечивает динамическое взаимодействие с веб-страницей. Переменные, условия, функции, события и DOM позволяют создавать поиск, тесты, меню и другие интерактивные элементы. CSS-анимации подходят для простых визуальных эффектов, а JavaScript применяется для более сложного поведения, связанного с логикой приложения.
